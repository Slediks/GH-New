# Arena local audio — sources and licensing

All recorded source assets are CC0 1.0 (https://creativecommons.org/publicdomain/zero/1.0/).
Checked on 2026-10-25. No attribution is required; these credits preserve provenance.

* pistol-1..3, rifle-1..3, shotgun-1..3, sniper-1..3: **The Free Firearm Sound Library**,
  recorded by Ben Jaszczak, Brian Nelson, Kevin Heras and Matthew Nanney.
  https://opengameart.org/content/the-free-firearm-sound-library
  Original archive: https://opengameart.org/sites/default/files/Prepared%20SFX%20Library.7z
  1911, AK-47, Mossberg and Tikka recordings, respectively. Three distinct takes per weapon.
* reload-pistol, reload-rifle, reload-shotgun, reload-sniper: **Gun reload sounds**,
  SpringySpringo. https://opengameart.org/content/gun-reload-sounds
  Original files: gunreload1.wav, assaultriflereload1_0.wav, shotguncock_0.wav.
  Sniper currently shares the rifle mechanism; shotgun uses a short pump/action cue,
  not a simulation of individual shell loading.
* step-1..5, jump, land, death, dry: **Impact Sounds**, Kenney.
  https://kenney.nl/assets/impact-sounds
  Original archive: https://kenney.nl/media/pages/assets/impact-sounds/87b4ddecda-1677589768/kenney_impact-sounds.zip
  Concrete footsteps, carpet takeoff, soft impacts and a light metal click.
  Death is a body impact, without voices. One universal surface set for Depot 07.

Delivery: mono PCM16 WAV, 44.1/48 kHz, approximately 1.62 MB total (25 files).
No runtime network dependencies. Mono avoids conflicting recorded stereo direction
when HRTF positioning is applied. Edits: cut single takes, remove DC and leading silence,
low-pass before 96→48 kHz decimation, normalize peaks, fade boundaries. No pitch
substitution between weapons. samples.json records exact source cuts and measurements.

Rebuild: scripts/prepare_arena_audio.py, optional authoring dependencies numpy/soundfile.
Full source archives are kept outside runtime/images in ignored data/arena-audio-sources.
UI cues are generated locally by GameHub's audioBuffers.ts; they are not third-party recordings.

Grenade throw, bounce, explosion and smoke cues are original synthesized PCM files
generated by `scripts/generate_grenade_audio.py`. They have no external source.
Flashbang detonation and ear ringing cues are generated by the same script.
Molotov bottle break, ignition, fire loop and fade cues are original synthesis from
the same script; no runtime network requests are made.
