# Последние ходы и жизненный цикл чата стола

Обновление 22.10.2026, существующая установка GameHub на HTTP 8080.

## История ходов

Общий React-компонент `boards/MoveHistory.tsx`: последовательный список,
номер, отображаемое имя участника, описание хода, выделение последней записи.
Ширина правой колонки ограничена 280–360 px. Лента прокручивается внутри блока
высотой до 320 px. Новые действия снизу; просмотр старых ходов не прерывается
автопрокруткой. Пустое состояние компактное.

Шахматы показывают уже рассчитанную движком SAN-нотацию. Шашки объединяют
обязательное продолжение взятия в `c3 × e5 × g7`. Нарды группируют перемещения
одного игрока за бросок с исходными кубиками, включая дубли, бар, снятие и
вынужденный пропуск. Номера пунктов совпадают с отображением доски.

Слой `boards/history.py` добавляет только данные представления в JSON состояния
раунда, не изменяя допустимые действия, случайность, таймеры или выплаты.
Хранятся последние 100 сгруппированных ходов с последовательными номерами.
Для существующих партий без этого поля представление восстанавливается из
сохранённых ответов журнала действий, без повторной симуляции. Исходная история
и финансовый журнал не удаляются.

## Очистка локального чата

Пользователь уточнил 22.10.2026: **сохранить нынешнюю модель освобождения мест**.
В шашках, шахматах, нардах и дуэлях завершение/отмена партии освобождает места,
поэтому чат очищается вместе с расчётом. Дополнительное пребывание после партии
не вводилось. В покере окончание раздачи само по себе не очищает чат:
при двух игроках выход первого сохраняет историю, выход последнего очищает её.
Боты учитываются существующей логикой освобождения мест. Disconnect и зрители
не являются основанием очистки.

`table_chat.clear_empty_table` вызывается в серверных точках освобождения мест
и аварийного возврата. Он удаляет `CasinoMessage` только данного `table.id`
и увеличивает `table.state.chat_generation` в той же транзакции. Повторная
завершённая операция не очищает чат повторно. Миграция схемы не требуется.
Глобальный канал `lobby` и общие комнаты не затронуты. Модерация не изменена.

Join, освобождение места, чтение и отправка локального сообщения используют
блокировку той же строки стола. После ожидания блокировки данные перечитываются,
в том числе при уже загруженном объекте SQLAlchemy. POST локального сообщения
передаёт `generation`, полученную из GET истории: отсутствующая/устаревшая версия
возвращает 409. Старые вкладки следует обновить. Общему чату версия не требуется.

Открытый интерфейс обновляется существующим опросом раз в 3 секунды. При новой
версии сбрасываются текущая страница, ранее загруженный архив и курсор. Поздние
ответы прежней версии игнорируются. Новая websocket-подписка не добавлена.
Чаты столов, которые уже были пусты до обновления, массово не очищаются:
очистка произойдёт при следующем реальном освобождении стола.

## Проверки и установка

- 51 существующая проверка настольных игр и связанных функций прошла.
- 11 новых проверок: области очистки, повторный запрос, запоздавшее сообщение,
  новый вход, покер 2→1→0, SAN, серии шашек, оба вида нард и дубли.
- PostgreSQL на существующем стенде: два конкурентных соединения, ожидание
  блокировки, отказ старой версии и пустая сохранённая история. Использован
  отдельный временный тестовый стол; его записи удалены после проверки.
- Playwright: все четыре вида истории, длинные имена, ручная прокрутка,
  выделение последнего хода, очистка загруженного архива, повторное открытие.
  Для визуального сценария использованы локальные подменённые ответы API:
  скриншоты демонстрируют оформление, а не настоящие партии или ставки.
- TypeScript, ESLint и Ruff прошли. Перед обновлением создана резервная копия
  `backups/table-chat-20261022/database.dump`. Пользователи, балансы и партии
  не обнулялись. Правила игр и боты не перерабатывались.
