# Мастерская Arena: авторы и права

Роль `author` открывает `/arena/creator`: карты, prefab и Custom Assets. Роль `admin` сохраняет полный доступ через мастерскую и панель Arena. Обычный пользователь не получает доступ к API редактора. Публикация и снятие с публикации остаются действиями администратора.

## Карты

`arena_maps.owner_user_id` хранит владельца. `arena_map_editors` хранит редакторов карты. Администратор имеет доступ по роли и не записывается в ACL. Владелец с активной ролью автора редактирует черновик, назначает и отзывает редакторов, может удалить свой ни разу не опубликованный черновик. Редактор с активной ролью автора может редактировать, проверять карту и создавать тестовую комнату. Он не управляет доступом и не удаляет карту. Администратор может передать владение другому автору; прежний владелец теряет доступ, если отдельно не включён в редакторы. Передача не меняет версию черновика.

Все запросы к черновику и действиям проверяют текущую роль и владение/ACL на сервере. Сохранение после отзыва доступа получает `403`; автосохранение останавливается. Конфликт версии черновика по-прежнему возвращает `409`. Редакторский WebSocket отсутствует; игровой WebSocket тестовой комнаты проверяет доступ к карте при подключении. Обычные матчи работают с опубликованным снимком карты и от ACL не зависят.

Копия чужой опубликованной карты создаётся из её зафиксированной опубликованной версии с новым владельцем. Редактор совместного черновика не может копировать неопубликованное содержимое в отдельную карту.

## Custom Assets и Prefabs

`arena_assets.owner_user_id` и `arena_prefabs.owner_user_id` назначаются при создании. Автор видит и редактирует свои черновики и использует опубликованные чужие источники только для чтения. Чужие черновики, ресурсы и предварительный просмотр закрыты. Администратор имеет полный доступ. Для источников отдельные редакторские ACL не предусмотрены. Публикация, отключение и архивирование остаются административными действиями.

## Миграция и восстановление

Миграция `c4912a780018` назначает владельцем автора из записи аудита создания, если она есть. Для старых объектов без такой записи берёт автора первой публикации, затем последнего редактора. Встроенные карты принадлежат существующему служебному пользователю GameHub. Новые карты устанавливаются с этим владельцем. Миграция добавляет внешние ключи и индексы, не меняя определения карт, опубликованные версии, матчи или файлы.

Перед запуском миграции на `gamehub:8080` требуется резервная копия базы и `game_files` по рабочей инструкции. При восстановлении возвращаются база и файлы из одной согласованной копии.
