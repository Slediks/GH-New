# Подкидной дурак: карточный интерфейс

## Что изменилось

Внутри существующей оболочки стола соперники расположены сверху, пары атаки и защиты — в центре, собственная рука — снизу. Карты 100×140 вместо прежних 72×102, с традиционными цветами мастей. Вся карта является кнопкой; доступные карты поднимаются при наведении и фокусе с клавиатуры, недоступные приглушены. При нескольких атаках защитник выбирает непокрытую карту на столе, затем карту своей руки.

Колода и открытый козырь объединены в одну стопку. Видны количество карт соперников, метки ботов, активный участник и отбой. Статус различает атаку, защиту, подкидывание и ожидание. Контекстные действия: «Взять», «Бито» в дуэли с покрытой атакой, «Пас» в общем круге подкидывания, «Закончить ход» после заявления защитника о взятии. Отдельной кнопки «Сыграть» и общей неоднозначной подписи больше нет.

## Источник допустимых действий

Сериализация существующих движков v1/v2 дополнена `legal_moves`: действие и индексы карты/цели только для текущего игрока. `durak_moves.py` проверяет кандидатов существующим `act` на глубоких копиях состояния. Исходный раунд не меняется, новые правила не дублируются на клиенте. Наблюдатель и ожидающий игрок получают пустой список. Закрытые руки и порядок колоды не добавлены в ответ.

Frontend показывает и отправляет только эти действия. При устаревшем состоянии окончательное решение по-прежнему принимает сервер. Порядок ходов, раздача, таймеры, ставки, комиссии, баланс, сохранение истории и транспорт realtime не изменены. Миграция не нужна; версия игровых правил прежняя. Backend с новым полем следует обновлять вместе с frontend: без поля новая рука безопасно неактивна.

## Компоненты и движения

- `durak/DurakTable.tsx` — композиция и выбор цели защиты.
- `durak/DurakCard.tsx` — карта и клавиатурная доступность.
- `durak/parts.tsx` — собственная рука, соперники, пары, колода.
- `durak/controls.tsx` — статус и контекстные действия.
- `durak/motion.ts` — движения по подтверждённым снимкам состояния.
- `durak/durak.css` — оформление только дурака.

Анимации длятся 240 мс: рука → стол, позиция соперника → стол, стол → отбой/получатель, колода → рука. Сопернику добираются только рубашки. До подтверждения сервера карта не разыгрывается визуально. Во время движения новые действия блокируются. При смене партии снимок сбрасывается. `prefers-reduced-motion` отключает перемещения; существующие мобильные стили не менялись, новая адаптация не добавлялась.

Ограничение: отображаются переходы между полученными снимками. Если за время отсутствия клиента прошло несколько ходов, интерфейс показывает актуальное состояние и не придумывает пропущенные анимации. Счётчики относятся к уже подтверждённому состоянию, декоративное движение не задерживает серверный ход.

## Проверка

Сервер: `test_casino_durak_multiplayer.py` и `test_durak_ui_moves.py` — 10 тестов, включая допустимость действий, неизменность исходного состояния, приватность, совместимость старого движка, многопользовательские партии. TypeScript и ESLint проходят.

Браузер: `durak-table.spec.ts` — атака, защита, отключение недоступных карт, отбой, взятие, добор, контекстные подписи, шесть участников, обе темы. Ответы стола здесь контролируемые, это проверка интерфейса, а не замена серверным тестам. `duel-room-shell.spec.ts` проверяет сохранение жизненного цикла общей оболочки для дурака и костей. Оба сценария прошли на финальной сборке: 2 passed. Docker-сборка завершилась успешно; Vite сообщает о существующем общем JS-пакете больше 500 КБ, разделение пакета не входит в этот редизайн.

Снимки: `screenshots/casino-2026-09/durak-trick.png`, `durak-table-desktop.png`, `durak-table-light.png`.

Сборка и браузерная проверка выполняются на изолированном Docker-стенде `127.0.0.1:18080`. Рабочая установка `8080` этим этапом не обновляется.
