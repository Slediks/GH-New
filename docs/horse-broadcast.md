# Скачки: спортивная трансляция

Обновление интерфейса от 7 октября 2026 года.

## До и после

- Зелёное сукно заменено песчаной трассой с тёмным спортивным табло.
- Убраны раскрывающиеся характеристики скорости, выносливости и вариативности.
- Участники представлены компактными кнопками: номер, цвет, имя, коэффициент и вероятность первого места.
- Табло показывает номер заезда, обратный отсчёт до старта, текущего лидера по серверным позициям и завершение заезда.
- Финиш выделяет победителей и показывает порядок по опубликованным сервером временам. При равенстве места одинаковые (1, 1, 3). Если времён нет, порядок не выдумывается.
- Личная ставка показывает выбранную лошадь, сумму и серверную выплату.

## Границы изменения

Изменён только frontend. Модель лошадей, вероятность, коэффициенты, расчёт исходов и выплат, история, кошельки, realtime и API сохранены. Старые поля характеристик остаются в контракте, но не выводятся в карточках. Процент — форматирование опубликованной дроби probability, а не оценка по характеристикам. Вероятность включает разделённое первое место, поэтому сумма процентов может превышать 100%.

HorseRace отображает полученные позиции; CSS интерполирует движение между ними. Декоративное движение не определяет исход. Существующие мобильные стили сохранены, новые не добавлены. Существующее отключение анимаций через prefers-reduced-motion сохранено.

## Проверка

- TypeScript, ESLint изменённых компонентов и Docker-сборка прошли.
- 2 модульных теста: опубликованная дробь, недопустимый знаменатель, ранжирование и ничьи, отсутствие данных.
- 1 браузерный сценарий Playwright: приём ставок, позиции и лидер, финиш с ничьей, личная выплата, переключение темы, отсутствие ошибок JavaScript.
- Визуально просмотрены desktop-снимки трансляции и финиша в тёмной/светлой темах. Браузерный сценарий использует публичные тестовые ответы для воспроизводимости и не меняет исходы или деньги на сервере.
