# Arena: чувствительность, fullscreen и фокус

Изменения от 26.10.2026 ограничены клиентским вводом и настройками игрока.

## Поведение

- «Чувствительность в прицеле» — множитель обычной чувствительности, диапазон
  0,1–2, по умолчанию 0,65. Сохраняется в `arena-preferences`, применяется сразу
  по обеим осям. Старые настройки получают значение по умолчанию.
- Множитель действует только при активном существующем scope. Его проверки
  оружия, перезарядки, жизни игрока и захвата мыши сохранены.
- Полный экран использует `requestFullscreen` игрового контейнера.
  Класс оформления следует `document.fullscreenElement`; ResizeObserver
  обновляет размер рендера. Вход запрашивает захват указателя; отказ браузера
  оставляет доступным обычный оконный режим.
- Escape открывает меню и выходит из полного экрана. Возвращение фокуса
  само по себе не захватывает мышь: требуется «Продолжить».

## Исправленная причина ложной паузы

Ранее любое сочетание Ctrl с другой клавишей вызывало общий сброс, который
одновременно очищал ввод, открывал меню и освобождал мышь. Это конфликтовало
с Ctrl для приседания при движении. Теперь назначенные игровые клавиши
обрабатываются и при удержании Ctrl; Alt/Meta очищают ввод, но сами не
притворяются потерей фокуса.

`input.ts` отвечает за клавиши и очистку удерживаемых действий. `focus.ts`
отвечает за переходы fullscreen/Pointer Lock и состояние игры. Настоящий
blur, скрытие документа и неожиданный выход из Pointer Lock останавливают
ввод. Технический blur при сохранённом фокусе не открывает меню.
Ожидаемые переходы имеют явное состояние и номер операции: завершение
старого запроса после ухода в фон не возобновляет игру. Таймеры подавления
событий не используются. mouseleave/mouseout и абсолютные координаты мыши
не служат причинами паузы.

## Проверки

- 31 клиентский тест Arena прошёл: ввод, scope, настройки, звук и переходы
  фокуса, в том числе отказ fullscreen и отмена незавершённого перехода.
- TypeScript и ESLint Arena прошли; production-сборка выполнена.
- Браузерный сценарий `arena-presentation.spec.ts` проверяет сохранение
  настройки, настоящий fullscreen, две минуты управления, повторный вход,
  Escape и существующие сценарии scope/наблюдения/переподключения.
  Сценарий прошёл на 8080 за 2,3 минуты (120 секунд непрерывного ввода).
  Снимок: `screenshots/arena-fullscreen-input.png`.
- После заключительной правки активации звука прошёл браузерный сценарий
  `arena-audio-network.spec.ts`: два браузера, реальные действия, отсутствие
  эха собственного выстрела, сохранение аудиоконтекста при fullscreen (17,3 с).
- Физический переход курсора на второй монитор и сочетания ОС не подтверждены
  автоматизацией браузера; настоящая потеря фокуса покрыта модульными тестами.

Сервер, комнаты, статистика и боевые правила не изменялись. Миграций нет.
Единственная установка для развёртывания — Compose `gamehub`, HTTP 8080.

Встроенный инструмент TODO в этой сессии недоступен. Три этапа отражались
в сообщениях о ходе работы; отдельный TODO-файл не создавался.
