# Arena Map Editor: оформление экземпляров assets

## Использование

Администрирование → Арена → Maps → Редактировать черновик → выбрать объект.
В правом инспекторе появился раздел **Appearance · внешний вид**.

- Палитра, HEX `#RRGGBB` и RGB меняют цвет выбранного экземпляра сразу во viewport.
- Список вариантов показывает только зарегистрированные для asset варианты.
- Шероховатость и металличность доступны по metadata, диапазон 0–1.
- Для декоративных ламп, панелей, вывесок и приборов доступны цвет свечения и
  интенсивность 0–3. Свечение материала не добавляет Point Light.
- «Сбросить цвет» удаляет индивидуальный цвет, возвращая цвет текущего варианта.
  «Сбросить материал целиком» удаляет все overrides и возвращает исходный asset.
- При нескольких выбранных объектах отображается пересечение доступных slots,
  параметров и вариантов. Разные значения обозначаются Mixed. Само выделение их не меняет.
- «Копировать оформление» копирует overrides одного объекта во внутренний буфер
  редактора. Вставка разрешена только для совместимых параметров и вариантов.
- Изменения участвуют в Undo/Redo, существующем автосохранении и явном сохранении.
  Дублирование объектов, выделенной группы и карты сохраняет overrides.

Материалы для Nature, стартов и игровых областей не редактируются. Источники света
сохраняют прежние собственные настройки цвета/интенсивности; они не являются emissive props.
Visibility остаётся отдельным свойством. Alpha, произвольная прозрачность, загрузка текстур,
URL, пути к файлам, shader/UV-параметры не добавлены.

## Системные варианты

Base Geometry и Urban: исходный материал, бетон, окрашенный металл, штукатурка, асфальт.
Industrial и Military: исходный, чистый, потёртый, ржавый, тёмный металл и армейская окраска.
Варианты — фиксированные сочетания цвета, шероховатости и металличности. Это материалы
текущей процедурной библиотеки, без новых текстурных карт ржавчины/царапин.
Произвольный цвет поверх варианта заменяет только его базовый цвет.

## Формат и совместимость

Необязательное расширение schemaVersion 1; миграция таблиц и переписывание старых карт
не требуются. Отсутствующее поле означает исходное оформление.

```json
{
  "assetId": "industrial.container",
  "assetVersion": 1,
  "materialOverrides": {
    "body": {
      "variant": "rusted",
      "baseColor": "#a64b3c",
      "roughness": 0.65
    }
  }
}
```

`body` — стабильный ID material slot. Metadata `materialSlots` описывает имя slot,
разрешённые fields и variants с отображаемыми названиями. Части ресурса могут явно
ссылаться на slot; существующие части без такого поля используют `body`. Таким образом,
формат допускает несколько материалов модели, не привязываясь к React-компонентам.

Исходные цвета/параметры assets v1 не изменены; добавлено описание допустимых настроек.
Registry не модифицируется при редактировании экземпляра. Опубликованный снимок хранит
его definition и metadata использованных assets, включая варианты. Существующие
опубликованные revisions без metadata читаются с прежними defaults.

Сервер проверяет имена slots/вариантов, доступность каждого поля, типы, конечность чисел,
диапазоны и шестизначный HEX без alpha. HEX нормализуется в нижний регистр; пустые
overrides удаляются. Неизвестные параметры и неподдерживаемый emissive отклоняются.
Проверка выполняется при сохранении, preview и публикации, через прежние endpoints.
Новые цвета не влияют на transforms, movement/bullet hulls, bounds и старты.

## Код и производительность

- `backend/app/arena/editor/materials.py`: metadata вариантов и проверка overrides.
- `frontend/src/features/arena/editor/materials.ts`: общий resolver, пул материалов,
  ключ объединения статической геометрии.
- `Appearance.tsx` и `ColorField.tsx`: инспектор и цветовые controls.
- `dataScene.ts`: единый путь построения для редактора, Play Test и Arena.

Resolver: defaults → вариант → параметры экземпляра. Материал никогда не изменяется
на месте, если им пользуется другой объект. Сцена переиспользует одинаковые конфигурации
через пул со счётчиком ссылок. При смене цвета освобождаются конфигурации, больше никем
не используемые. Live preview обновляет материалы, сохраняя геометрию объектов.
Сохранение по каждому движению палитры не отправляется — используется прежний debounce.

В игровом renderer объединение учитывает не только цвет, но и roughness, metalness,
emissive и остальные существенные флаги материала, а также настройки теней.
У разных материалов одинакового цвета параметры не теряются. Оригинальные hardcoded
карты и их собственные instanced meshes не переоборудованы под overrides.

## Проверки и эксплуатация

Проверки размещены в `backend/tests/test_arena_materials.py`,
`frontend/src/features/arena/editor/materials.test.ts`,
`frontend/e2e/arena-materials.spec.ts`, `frontend/e2e/arena-material-performance.spec.ts`.
Сценарий Test Room в `arena-editor.spec.ts` также проверяет сохранение прежнего цвета
после публикации новой версии.

Прогон 02.11.2026: **223 серверных и 59 клиентских проверок**, пять браузерных сценариев
редактора/материалов/комнат прошли через HTTP `192.168.1.10:8080`, desktop Edge.
Проверены отказ недопустимому материалу, независимость экземпляров, неизменность hulls,
сброс, копирование, дублирование, Mixed, Undo/Redo, автосохранение, повторное открытие,
Play Test, обычный матч и закрытая тестовая комната. В активном обычном матче revision 1
осталась красной после публикации синей revision 2, в том числе после reconnect.

Проверка пула: 400 объектов требуют 1, 5 или 400 материалов для соответствующего числа
конфигураций; после удаления объектов пул пуст. 1000 смен цвета одного экземпляра
не накапливают неиспользуемые материалы. Численные браузерные измерения большой сцены
записаны в `arena-material-performance.json`; они относятся только к текущему компьютеру.
В сцене из 442 объектов (400 добавленных props) сравнивались defaults, 1, 5 и 400
конфигураций: во всех случаях медиана кадра 13,3 мс, p95 13,4 мс, около 75 FPS.
Это измерение ограничено частотой кадров текущего браузера. В отдельной проверке игровой
batching объединяет 400 объектов соответственно в 1, 5 или 400 meshes, сохраняя различия
roughness даже при одинаковом цвете.
Скриншот: `screenshots/arena-material-overrides.png`.

Развёртывание — прежний Compose `gamehub`, только 8080. Авторизация, пользователи,
балансы и исторические карты не менялись. Проверочные опубликованные карты отключаются,
а их revisions сохраняются. Неопубликованный нагрузочный черновик удаляется после теста.

Встроенный TODO-инструмент Codex в сессии недоступен; отдельный tracking-файл не создавался.
Этапы и результаты сообщались в чате.
