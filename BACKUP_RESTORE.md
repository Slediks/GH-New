# Резервная копия и восстановление

```powershell
.\scripts\offline.ps1 backup
.\scripts\offline.ps1 restore -BackupPath .\backups\gamehub-<version>-<time> -ConfirmRestore
```

Backup на короткое время останавливает приложения, затем сохраняет согласованный `pg_dump` PostgreSQL, том загруженных файлов (`game_files`), текущие `.env` и `deploy/games.conf`. В каталоге `backups/` создаются manifest и SHA-256. После копирования приложения запускаются вновь. Секреты в копии: храните этот каталог с ограниченным доступом. `backups/` исключён из Git и Docker build context.

Restore проверяет хеши **до** изменения данных, создаёт дополнительную страховочную копию текущего состояния, останавливает приложения, восстанавливает БД и файловый том, возвращает конфигурацию и запускает сервисы. Флаг `-ConfirmRestore` обязателен, потому что текущие данные заменяются данными выбранной копии.

На Linux: `bash scripts/offline.sh backup` и `CONFIRM_RESTORE=YES bash scripts/offline.sh restore backups/<каталог-копии>`.

Для проверки без замены рабочей базы используйте `pg_restore --list` на архиве или восстановление на отдельной машине по процедуре установки. На рабочей машине GameHub не создавайте второй Compose-проект или порт только ради проверки.
